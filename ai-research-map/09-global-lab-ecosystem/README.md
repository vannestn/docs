## The shape of this area

> **📦 Concept: "open-weight" vs "closed"** — *Open-weight* models release the trained
> parameters so anyone can run/modify them (e.g., DeepSeek, Qwen, Llama, OLMo). *Closed*
> models are accessed only via an API (e.g., GPT-5, Claude, Gemini). A model can be
> open-weight without being fully "open-source" (which would also release training data/code).

Two big stories: (1) **architectural innovation went global** — much of the best efficient-
architecture work (linear-attention hybrids, trainable sparse attention, the Muon optimizer
at scale) now comes from **Chinese labs**, shipped as competitive open weights; (2) a
**fully-open movement** (Ai2's OLMo releasing data+code+checkpoints, EleutherAI's clean
corpora, decentralized training by Prime Intellect/Nous) pushes transparency as a research
value. The competitive/geopolitical framing is in
[12 · Geopolitics](../12-politics-capital-and-business-models/geopolitics-and-policy.md).
