# Radar digests

Weekly scans (`<YYYY>-W<WW>.md`) and monthly reviews (`monthly-<YYYY>-<MM>-review.md`)
produced by the scheduled radar agents. Spec and coverage clusters:
[06-radar-design.md](../06-radar-design.md).

Digests **propose** index/ledger changes; they are applied deliberately in working
sessions, never automatically.
