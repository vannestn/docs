# Problem 08 — Model Architecture Research (assessed for a non-architecture-specialist)

**One-line:** Frontier architecture design is lab-scale by construction, but three adjacent niches — small-scale architecture *science*, independent stress-testing of architecture *claims*, and architecture-*behavior* studies — have a real solo track record and live gaps.

Grounding doc (read first, verified against primary sources): [`ai-research-map/02-architectures-and-training/post-transformer-architectures.md`](../../ai-research-map/02-architectures-and-training/post-transformer-architectures.md)

---

## The problem, concretely

**What's at stake.** Softmax attention (the standard transformer mechanism where every token compares against every other) costs grow with the square of context length; the field is racing to replace or dilute it with sub-quadratic primitives — building blocks whose cost grows slower than that square (SSMs = state-space models, which carry a fixed-size running summary instead of re-reading the whole context; gated linear attention, an attention variant with cheaper linear cost plus learned "gates" that decide what to keep; RNN revivals, updated recurrent networks; test-time-training memory, a memory module that keeps learning during inference). The current production answer is *hybrids* — a few full-attention layers among many linear ones — shipping in Kimi Linear ([arXiv:2510.26692](https://arxiv.org/abs/2510.26692)), MiniMax-M1 ([arXiv:2506.13585](https://arxiv.org/abs/2506.13585)), Qwen3-Next ([weights, no paper](https://huggingface.co/Qwen/Qwen3-Next-80B-A3B-Instruct)), Hunyuan-TurboS ([arXiv:2505.15431](https://arxiv.org/abs/2505.15431)), Falcon-H1 ([arXiv:2507.22448](https://arxiv.org/abs/2507.22448)).

**Why frontier design work is mostly closed to a solo researcher (facts, not vibes):**
- Decisive ablations (controlled experiments that toggle one design choice to isolate its effect) are run at *matched trillion-token budgets*: Kimi Linear's headline claim ("first linear-attention hybrid to beat full attention") rests on matched **1.4T-token** training runs; Hunyuan-TurboS trained on **16T tokens**; MiniMax-M1's RL phase alone used **512 H800s for 3 weeks (~$0.53M)** (all from the papers above, via the map doc).
- The work is entangled with kernel engineering (writing low-level GPU code — e.g. Mamba-2's SSD block algorithm, a hardware-efficient way to compute state-space updates, [arXiv:2405.21060](https://arxiv.org/abs/2405.21060)) and training-stability firefighting at scale (MiniMax-M1 and Hunyuan-TurboS both report needing FP32 — full 32-bit precision — for SSM/output states to avoid numerical blowups).
- This is a documented structural trend, not an impression: Besiroglu et al., ["The Compute Divide in Machine Learning"](https://arxiv.org/abs/2401.02452) (what they did: tracked who authors ML papers by compute intensity; finding: academic-only teams' representation is shrinking precisely in compute-intensive topics like foundation models).

**The measurable sub-problems that remain open at small scale:**
1. **The recall/state-capacity wall** — pure sub-quadratic models fail exact recall (pulling back a specific earlier detail verbatim) as context grows (RWKV-7 passkey collapse past ~28K — a "passkey" test hides a code in a long text and asks the model to retrieve it, [arXiv:2504.21463](https://arxiv.org/abs/2504.21463); Mamba-2/TTT/DeltaNet fail S-NIAH past ~8K — S-NIAH = single needle-in-a-haystack, the same retrieval test, [arXiv:2501.00663](https://arxiv.org/abs/2501.00663)). *Where exactly* each new primitive hits the wall is measurable at <1B params.
2. **Claim verification** — headline claims (e.g. "outperforms full attention," "10× throughput") are almost all self-reported by the releasing lab; Qwen3-Next shipped with **no paper at all**. Independent behavioral evaluation is a distinct, tractable sub-problem.
3. **Trick transfer** — do architecture/training tricks discovered at one scale, dataset, and loss target (the specific objective the model is trained to minimize) survive changes to any of these? The one rigorous audit that exists (optimizers) found most claimed 2× speedups shrink to ≤1.4× under fair tuning ([arXiv:2509.02046](https://arxiv.org/abs/2509.02046)).
4. **Architecture → behavior mapping** — how a fixed-size recurrent state (the model's compressed running memory) vs. a KV cache (the transformer's stored key/value vectors for every past token, which grows without bound) changes *behavior* (copying fidelity, in-context learning — learning a task from examples in the prompt with no weight updates, state tracking, hallucination under long-context retrieval) is only partially charted, mostly for 2024-era Mamba, not the 2025–26 production primitives (KDA = Kimi Delta Attention; Gated DeltaNet variants).

## The research field around it

Four sub-areas with different maturity:

- **Frontier primitive design + scaling (mature, lab-owned).** SSMs and duality theory (Mamba-2/SSD — the paper showing state-space models and attention are two views of the same math, [arXiv:2405.21060](https://arxiv.org/abs/2405.21060)); production hybrids (Kimi Linear, MiniMax-M1, Qwen3-Next, Hunyuan-TurboS, Falcon-H1); test-time-training memory (Titans [arXiv:2501.00663](https://arxiv.org/abs/2501.00663), Nested Learning/"Hope" — a framework treating a model as nested optimization loops, [arXiv:2512.24695](https://arxiv.org/abs/2512.24695)). Contested design choices — interleaved vs. parallel hybrid layout (how the attention and linear layers are arranged), fine-grained vs. scalar gating (per-channel forget gates vs. one shared scalar) — are ablated in-house at scale.
- **Small-scale architecture science (established methodology, open to individuals).** Synthetic-task probing (testing models on tiny hand-built tasks that isolate one skill) that predicts scale behavior: Zoology (what it did: diagnosed why sub-quadratic models trail attention using a small-model playground; finding: associative recall — matching a cue to its previously-seen partner — accounts for **>82% of the perplexity gap** between sub-quadratic models and attention; perplexity = a standard next-token prediction-error score, lower is better) ([Hazy Research blog](https://hazyresearch.stanford.edu/blog/2023-12-11-zoology1-analysis), [arXiv:2312.04927](https://arxiv.org/abs/2312.04927)); MAD (what it did: built synthetic "unit tests" — small diagnostic tasks — that correlate with compute-optimal perplexity and used them to design better hybrids, [arXiv:2403.17844](https://arxiv.org/abs/2403.17844)); Physics of Language Models Part 4.1 (what it did: uses fully synthetic pretraining to isolate architectural effects and proposes Canon layers — added local-mixing layers that boost reasoning) ([SSRN](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5240330), [code](https://github.com/facebookresearch/PhysicsLM4)). The **speedrun tradition** (open leaderboards racing to train a small model to a target quality in the least time) operationalizes this: [modded-nanogpt](https://github.com/KellerJordan/modded-nanogpt) (84 records, 45 min → **1.32 min** as of May 2026), [cifar10-airbench](https://github.com/KellerJordan/cifar10-airbench), and [Marin speedrun](http://marin.community/blog/2025/05/19/announcement/) (multi-budget tiers). The **BabyLM Challenge** (a shared competition to pretrain on a child-sized amount of text; 4th edition at EMNLP 2026, tracks at 10M/100M words + new multilingual track) explicitly lists "architecture innovation" in scope ([2026 CFP](https://www.alphaxiv.org/overview/2602.20092v2), [2025 proceedings](https://aclanthology.org/events/babylm-2025/)).
- **Reproduction / stress-testing of architecture claims (small but respected).** Theory + small experiments deflating claims: "The Illusion of State in State-Space Models" (what it did: proved SSMs are stuck in TC⁰ — a low complexity class transformers also sit in, meaning they can't do certain sequential computations; finding: their "state" advantage for state-tracking is illusory) ([arXiv:2404.08819](https://arxiv.org/abs/2404.08819)); "Repeat After Me" (what it did: proved and measured a copying gap caused by fixed-size states — models with bounded memory can't reliably copy long strings) ([arXiv:2402.01032](https://arxiv.org/abs/2402.01032)); NVIDIA's matched-data 8B Mamba-vs-Transformer study (finding: pure Mamba lags on MMLU — a broad knowledge exam — and phonebook-recall, while hybrids win) ([arXiv:2406.07887](https://arxiv.org/abs/2406.07887)); "Fantastic Pretraining Optimizers" (what it did: audited 10 optimizers under fair tuning; finding: cut claimed speedups roughly in half) ([arXiv:2509.02046](https://arxiv.org/abs/2509.02046)).
- **Architecture-behavior studies (young, fragmented).** ICL (in-context learning) comparisons: Mamba matches transformers on many ICL tasks but SSMs fail retrieval/decision-tree tasks while transformers fail sparse parity (a needle-in-noise bit-counting task), motivating the MambaFormer hybrid ([arXiv:2402.03170](https://arxiv.org/abs/2402.03170), [arXiv:2402.04248](https://arxiv.org/pdf/2402.04248)). Long-context recall curves per architecture exist in scattered form (RULER numbers — RULER is a standard long-context stress benchmark — in each hybrid's own paper). Behavior-level measures (faithfulness, hallucination under retrieval, instruction following) by architecture are largely absent — see gaps.

## Who does this work

- **Frontier hybrid design:** Moonshot, MiniMax, Alibaba Qwen, Tencent, TII (state-funded UAE institute — Falcon-H1), Google Research (Titans/Hope), NVIDIA (hybrid empirical study, [arXiv:2406.07887](https://arxiv.org/abs/2406.07887)). Company-funded; closed to outsiders except via open weights.
- **Academic groups doing small-scale architecture science:** Stanford Hazy Research (Chris Ré — Zoology/Based/MAD lineage, [blog](https://hazyresearch.stanford.edu/blog/2023-12-11-zoology0-intro)); Princeton/CMU (Tri Dao, Albert Gu); NYU + AI2 (Merrill/Petty/Sabharwal — expressivity stress tests, i.e. proving what a given architecture can and can't compute); Harvard Kempner (Jelassi/Kakade — copying); Meta FAIR (Allen-Zhu's Physics of LM, [site](https://physics.allen-zhu.com/part-4-architecture-design/part-4-1)); University of Oslo LTG (BabyLM winners, "fully funded by the University of Oslo" per [arXiv:2410.24159](https://arxiv.org/abs/2410.24159)). Grant/university funding.
- **Open community labs:** **Marin** (Stanford CRFM/HAI — the Center for Research on Foundation Models / Human-centered AI institute) runs model development fully in the open — anyone can propose, review, and run experiments via GitHub, and its speedrun "accepts submissions at multiple compute budgets" ([announcement](http://marin.community/blog/2025/05/19/announcement/), [repo issues](https://github.com/marin-community/marin/issues/1981)). **RWKV** (an RNN-style architecture designed to train like a transformer) was initiated and led by an individual (Bo Peng / BlinkDL) and is now a Linux Foundation AI & Data incubation project with a Discord-organized contributor community ([LF page](https://lfaidata.foundation/projects/rwkv/), [repo](https://github.com/BlinkDL/RWKV-LM)). Nonprofit/foundation + volunteer funding models.
- **Individuals (the speedrun tradition):** Keller Jordan (modded-nanogpt + cifar10-airbench; the **Muon optimizer** — a newer training algorithm that updates weight matrices via an orthogonalization step — debuted as speedrun record #3, Oct 2024, per the [repo](https://github.com/KellerJordan/modded-nanogpt)); tysam-code (hlb-CIFAR10, the prior CIFAR speed record per [arXiv:2404.00498](https://arxiv.org/abs/2404.00498)); Tyler Romero (solo worklog on 2×RTX 4090 — consumer gaming GPUs, 8.13h → 2.55h, [worklog](https://www.tylerromero.com/posts/nanogpt-speedrun-worklog/)); record contributors like @sisovicm (current 1.320-min record). Hobbyist/self-funded; **Prime Intellect** (a company) sponsors validation runs for record attempts and hosts a [leaderboard](https://app.primeintellect.ai/speedrun/nanogpt).
- **How outsiders contribute, concretely:** PRs to modded-nanogpt (rules: same data pipeline, p<0.01 significance on the loss target — a strict statistical bar that the improvement is real, not luck — faster on identical 8×H100 hardware — [repo](https://github.com/KellerJordan/modded-nanogpt)); GitHub experiment proposals to Marin at any compute budget; BabyLM shared-task submissions (10M/100M-word budgets are single-GPU-trainable; [2026 CFP](https://www.alphaxiv.org/overview/2602.20092v2)); RWKV community channels; workshop/arXiv reproduction papers.

## Published exemplars (small-team/solo favored)

1. **modded-nanogpt speedrun leaderboard** — Keller Jordan + community, 2024–26 ([repo](https://github.com/KellerJordan/modded-nanogpt)). 84 records took GPT-2(124M)-to-3.28-loss (a 124M-parameter model trained to a fixed target loss) from 45 min to 1.32 min; individual PRs contributed rotary/QK-norm (position and attention-normalization tweaks), FP8 (8-bit training), attention-window scheduling, multi-token prediction (predicting several future tokens at once), bigram hash embeddings. Mattered because it produced the Muon optimizer and became the field's de-facto shared testbed for small-scale training/architecture tricks.
2. **"94% on CIFAR-10 in 3.29 Seconds on a Single GPU"** — Keller Jordan, solo author ([arXiv:2404.00498](https://arxiv.org/abs/2404.00498); now 2.59s with Muon per [repo](https://github.com/KellerJordan/cifar10-airbench)). Mattered as proof that one person on one GPU can do publishable, rigorous training-science, and as explicit infrastructure for cheap experiments ("airbench").
3. **RWKV** — initiated and led by one independent researcher, Bo Peng, grown into an LF AI & Data project ([arXiv:2305.13048](https://arxiv.org/abs/2305.13048); RWKV-7 [arXiv:2503.14456](https://arxiv.org/abs/2503.14456); [LF page](https://lfaidata.foundation/projects/rwkv/)). Mattered as the existence proof that an individual-led architecture line can stay competitive for years.
4. **GPT-BERT ("GPT or BERT: why not both?")** — 2 authors, University of Oslo ([arXiv:2410.24159](https://arxiv.org/abs/2410.24159), [code](https://github.com/ltgoslo/gpt-bert)). Won *both* BabyLM 2024 tracks by fusing masked and causal objectives (BERT-style fill-in-the-blank + GPT-style next-word prediction) in one stack, trained on ≤100M words. Mattered as the canonical "small budget, real architecture contribution" result.
5. **"The Illusion of State in State-Space Models"** — 3 authors, NYU/AI2, ICML 2024 ([arXiv:2404.08819](https://arxiv.org/abs/2404.08819)). Theory + small experiments showing SSMs cannot express permutation composition (tracking the net effect of a sequence of swaps — a task requiring true sequential state; TC⁰-bounded means their circuit depth is too shallow for it), deflating the "recurrence gives real state" narrative with near-zero compute. Mattered as a template for compute-free claim-stress-testing.
6. **"Repeat After Me"** — 4 authors, Harvard, ICML 2024 ([arXiv:2402.01032](https://arxiv.org/abs/2402.01032), [code](https://github.com/sjelassi/transformers_ssm_copy)). Proved 2-layer transformers copy exponential-length strings while fixed-state models can't; verified on pretrained models. Mattered because it turned an architecture property into a cheap behavioral probe anyone can run.
7. **Zoology / Based** — Hazy Research, small academic team ([arXiv:2312.04927](https://arxiv.org/abs/2312.04927), [blog series](https://hazyresearch.stanford.edu/blog/2023-12-11-zoology1-analysis), [Based](https://hazyresearch.stanford.edu/blog/2024-03-03-based)). Quantified that associative recall drives >82% of the sub-quadratic quality gap, then *designed a new architecture from the diagnosis* (Based — a linear-attention design that adds back the missing recall). Mattered as the model workflow: synthetic diagnosis → architecture fix.
8. **"Fantastic Pretraining Optimizers and Where to Find Them"** — 4 authors, Stanford ([arXiv:2509.02046](https://arxiv.org/abs/2509.02046); follow-up [arXiv:2606.16899](https://arxiv.org/html/2606.16899)). Fair-tuning audit (retuning every baseline equally hard before comparing) found claimed 2× optimizer speedups are really ≤1.4× and shrink with scale (Muon ~1.1× at 1.2B params). Mattered as the exemplar of *stress-testing training claims* — the same audit style has not been applied to most architecture claims.

## Where the gaps are

- **No independent verification of the 2025–26 hybrid headline claims.** Kimi Linear's "first linear architecture to outperform full attention" ([arXiv:2510.26692](https://arxiv.org/abs/2510.26692)) is self-reported; Qwen3-Next shipped weights with **no paper** ([HF card](https://huggingface.co/Qwen/Qwen3-Next-80B-A3B-Instruct)). The independent-eval literature (Illusion of State, Repeat After Me, NVIDIA study) targeted 2024-era Mamba/S4 (the original state-space architectures) — I found no third-party behavioral stress-test of KDA or the Gated-DeltaNet-family primitives (GDN = Gated DeltaNet, a linear-attention variant with a learned "delta rule" write and forget gates) in this research pass. ⚠️ absence claim: "not found," not "doesn't exist."
- **Trick-transfer is unaudited beyond optimizers.** The Stanford optimizer audit ([arXiv:2509.02046](https://arxiv.org/abs/2509.02046)) showed baseline undertuning (comparing against a weakly-tuned reference) inflates claims; the 84 modded-nanogpt records optimize *one* loss target on *one* dataset at *one* scale ([repo](https://github.com/KellerJordan/modded-nanogpt)) — whether records' architectural components (bigram hash embeddings; paired-head attention; MUDD skips — "multi-branch dynamic dense" skip connections) help at other scales/targets is untested publicly. MAD's synthetics-predict-scaling claim ([arXiv:2403.17844](https://arxiv.org/abs/2403.17844)) was validated on 2024 primitives, not the current gated-delta family.
- **Recall-wall cartography is stale.** The passkey/S-NIAH break points (the context length at which retrieval collapses) are documented for RWKV-7 (~28K) and Mamba-2/TTT/DeltaNet (~8K) ([arXiv:2504.21463](https://arxiv.org/abs/2504.21463), [arXiv:2501.00663](https://arxiv.org/abs/2501.00663)) but not, per this pass, for channel-wise-gated KDA (a forget gate per feature channel) vs. scalar-gated GDN (one shared gate) at matched small scale — exactly the contested design axis the map doc identifies. ⚠️ absence claim.
- **Behavior-level consequences are uncharted.** ICL-task differences are known ([arXiv:2402.03170](https://arxiv.org/abs/2402.03170), [arXiv:2402.04248](https://arxiv.org/pdf/2402.04248)), but no work found connects architecture class to hallucination rate / faithfulness under long-context RAG-style use (RAG = retrieval-augmented generation — feeding the model retrieved documents to answer from) — despite lossy fixed-size states (compressed memory that discards detail) being a mechanistically plausible cause. ⚠️ inferred gap (mechanism read from papers; the missing study is my inference from not finding one).
- **The speedrun niche is being automated.** Prime Intellect is running autonomous-agent speedrun research (AI agents that propose and test their own speedups — [auto-nanogpt](https://www.primeintellect.ai/auto-nanogpt)) and frontier coding agents have been benchmarked against the human record with 512 H100-hour budgets ([NanoGPT-Bench](https://github.com/IntologyAI/NanoGPT-Bench)) — human comparative advantage may shift from trick-finding to claim-auditing and behavior science. ⚠️ partly inferred from search-result summaries; repos opened only via search.

## What a solo researcher could do here

(Study shapes with cost/method facts; no ranking.)

1. **Speedrun-record component audit.** Take the last N modded-nanogpt records, re-ablate each component at a *different* loss target/dataset/scale, and report which gains survive — the optimizer-audit methodology ([arXiv:2509.02046](https://arxiv.org/abs/2509.02046)) applied to architecture tricks. The current record run is ~1.3 min on 8×H100; hundreds of full runs fit in a $500 rental budget, and the repo's own p<0.01 significance rule ([repo](https://github.com/KellerJordan/modded-nanogpt)) supplies the statistical framing. Tyler Romero's 2×4090 worklog shows the consumer-hardware variant ([worklog](https://www.tylerromero.com/posts/nanogpt-speedrun-worklog/)).
2. **Recall-wall map for the 2025–26 primitives.** Zoology/MAD-style synthetic suite (associative recall, copying, permutation composition per [arXiv:2402.01032](https://arxiv.org/abs/2402.01032)/[arXiv:2404.08819](https://arxiv.org/abs/2404.08819)) run at matched <400M scale across KDA-style channel-wise gating vs. GDN scalar gating vs. Mamba-2 vs. RWKV-7 — directly testing the contested gating axis at costs the Zoology team already demonstrated are small-lab-scale ([arXiv:2312.04927](https://arxiv.org/abs/2312.04927)).
3. **Independent behavioral stress-test of a released hybrid.** Open weights exist across sizes (Falcon-H1 0.5B–34B [arXiv:2507.22448](https://arxiv.org/abs/2507.22448); RWKV-7; Qwen3-Next). Run the published probe batteries (copying, phonebook/NIAH per [arXiv:2406.07887](https://arxiv.org/abs/2406.07887), state-tracking) as *inference-only* evaluation — running the trained model, no training compute — and compare against each model's own claims. This is the eval-methodology skill set applied to architecture.
4. **Architecture × hallucination study.** Matched-scale models of different architecture classes evaluated on RAG-style long-context tasks with an LLM-as-judge (using a strong model to grade another model's outputs) faithfulness pipeline — a direct extension of the researcher's published judge work to the open architecture-behavior gap above. Frontier-API judge + local small models keeps it in budget.
5. **BabyLM 2026 architecture entry.** The 10M/100M-word tracks are explicitly architecture-innovation-friendly and single-GPU trainable; the 2024 dual-track winner was a 2-author university project ([arXiv:2410.24159](https://arxiv.org/abs/2410.24159); [2026 CFP](https://www.alphaxiv.org/overview/2602.20092v2)). A hybrid-primitive entry (e.g., linear-attention layer mixes at BabyLM scale) would be novel to the venue. ⚠️ "novel to the venue" unverified — 2026 submissions not yet public.
6. **Marin open-lab experiment.** Propose and run an architecture-comparison experiment through Marin's GitHub process, which accepts speedrun submissions "at multiple compute budgets" ([announcement](http://marin.community/blog/2025/05/19/announcement/)) — a path to co-authorship-style credit inside an academic open lab without employment.

## What we still don't know

- Whether Kimi Linear's matched-scale "beats full attention" result replicates under independent training or even independent *evaluation* (no third-party check found).
- Whether MAD-style synthetic unit tests remain predictive for the gated-delta primitive family (validated only on 2024 primitives).
- Whether nanoGPT-speedrun components transfer across scale/dataset/loss-target (no published audit found; optimizer analogue suggests substantial shrinkage).
- Where KDA/GDN variants hit the recall wall relative to Mamba-2/RWKV-7 at matched scale.
- Whether architecture class measurably shifts hallucination/faithfulness behavior at matched capability (no study found; mechanism plausible).
- How fast agent-driven speedrunning ([auto-nanogpt](https://www.primeintellect.ai/auto-nanogpt), [NanoGPT-Bench](https://github.com/IntologyAI/NanoGPT-Bench)) erodes the human trick-finding niche, and whether claim-auditing resists automation similarly. ⚠️ speculative framing.
- Whether an 80B-A3B-class hybrid (Qwen3-Next; 80B total parameters but only ~3B active per token — a mixture-of-experts design) can be *meaningfully* stress-tested inference-only within a $500 budget (quantized — reduced-precision to shrink memory — local/rented inference feasibility unverified).
- BabyLM 2026 deadlines and evaluation pipeline details (CFP fetched did not include dates).

## Fit notes

The profile's strongest verified asset — published LLM-as-a-judge evaluation methodology — maps onto the two niches with the clearest documented gaps: independent stress-testing of self-reported architecture claims and architecture-behavior measurement, both of which are inference-heavy rather than training-heavy. The $500/study budget covers speedrun-scale training (current record ~1.3 min on 8×H100) and <400M-param synthetic-task ablations, the scales at which Zoology, MAD, and the BabyLM winners operated. Data-pipeline skills apply directly to building synthetic-task harnesses and eval batteries; no CUDA-kernel expertise is required for any of the six study shapes above, though it is required for frontier primitive design. Precedent exists for every participation channel named (PR-based leaderboards, shared tasks, open-lab GitHub experiments, solo arXiv papers).
